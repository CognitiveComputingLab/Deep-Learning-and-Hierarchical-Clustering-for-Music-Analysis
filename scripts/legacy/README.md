# Legacy and exploratory scripts

The dissertation's only supported orchestration entry point is
`scripts/run_dissertation_experiments.py`.  Historical visual demos,
additive-DP experiments, boundary-aware prototypes, and
`src/cross_dataset_eval.py` are retained for provenance but are not sources
of headline dissertation results.  In particular, cross-dataset pairwise TED
between human annotation trees is not model evaluation.

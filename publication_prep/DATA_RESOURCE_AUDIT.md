# Candidate resources with multi-level annotations

The next dataset should be chosen by **annotation semantics and aligned musical input**, not by the presence of a tree-shaped file alone. This is an audit of resources already in the workspace, plus two public alternatives. No candidate below has been added to the reported ABC or Taking Form experiments.

| Resource | Explicit hierarchy and continuity | Musical input and alignment | Local coverage and immediate use | Reuse information visible in source |
|---|---|---|---|---|
| [Algomus Mozart string quartets](https://gitlab.com/algomus.fr/algomus-data/-/tree/master/quartets/mozart) | `.dez` labels include numbered `top.*` sonata-form levels as timed spans; other layers include events or different analyses and should be kept separate. | The local files are annotation JSON, not paired score-note tables. Aligning the exact quartet movement/edition and repeat convention is still required. | 32 local `.dez` movement files; converted to the shared annotation format, but **not** an additional scored tree-evaluation set. | Local README identifies the data and citation, but a corpus-specific license for redistribution was not identified in the snapshot. Record source and check terms before repackaging. |
| [Jazz Harmony Treebank (JHT)](https://archives.ismir.net/ismir2020/paper/000080.pdf) | Full harmonic syntax trees over chord sequences, with labelled prolongation/preparation relations; they are not coarse-to-fine *formal sections*. | The local treebank contains chords, beats, and measures. It does not contain paired note-score pitch-class bins for the existing pipeline. A chord-leaf adapter and a distinct task definition would be needed. | Local `treebank.json` has 1,170 chord-chart entries, of which 150 contain a nonempty `trees` field. Useful as a grammar/harmonic-syntax comparator, not a direct Taking Form replication. | [Paper](https://archives.ismir.net/ismir2020/paper/000080.pdf) and local `jazz-arbres/Readme.md` document provenance; explicit redistribution terms for this bundled copy were not identified locally. |
| [BPS-FH](https://github.com/Tsung-Ping/functional-harmony) | The author repository offers form/phrase information and points users to a Taking Form conversion; inspect the converted levels before claiming an independent hierarchy. | Symbolic note events and beat positions are supplied, which could make input preparation easier. | Candidate only. Its Beethoven first-movement scope overlaps the existing Taking Form repertoire, so it cannot automatically be counted as independent evidence. | The author repository supplies a license file; verify the version and annotation subset before reuse. |
| [SALAMI](https://github.com/DDMAL/salami-data-public) | Multiple annotated layers of musical structure, often by more than one annotator; its hierarchy underlies [T-measure evaluation](https://archives.ismir.net/ismir2015/paper/000174.pdf). | Annotations are in recording time, while this pipeline requires symbolic score bins; corresponding audio or score alignment is not in the current workspace. | Candidate for an audio-based extension or evaluation-method comparison, not a direct symbolic-score test. | The dataset repository states CC0 for annotations and notes that it cannot redistribute the audio. |

## Integration decision for the current paper

Taking Form remains the strongest immediately runnable **form-hierarchy** target. The Algomus Mozart labels are the nearest additional symbolic form candidate, but exact score pairing and timing alignment are necessary before metrics can be reported. JHT asks a different harmonic-syntax question, and SALAMI requires an audio-input path. BPS-FH should be checked for overlap before any new test split is designed.

No researcher contact is required to interpret the current saved results. If the paper later needs to redistribute Algomus annotations or score-aligned derivatives, the missing corpus-specific reuse terms and exact score edition are concrete questions to raise with the maintainers. A message should name the files and intended use; it has not been sent.
